# Contests

โฟลเดอร์นี้ใช้สำหรับเก็บโค้ดและบันทึกจากการซ้อมแบบ Contest หรือการแข่งขันจริงของทีม ICPC

เป้าหมายของโฟลเดอร์นี้ไม่ใช่แค่เก็บคำตอบของโจทย์ แต่ใช้เพื่อดูพัฒนาการของทีม วิเคราะห์ข้อผิดพลาด และวางแผนซ้อมครั้งต่อไป

---

## Folder Purpose

ใช้สำหรับเก็บ:

- Mock contest
- ICPC practice contest
- Codeforces Gym
- AtCoder contest
- Kattis / ICPC archive contest
- การซ้อมจับเวลาแบบทีม
- การแข่งขันจริง

---

## Folder Naming Rule
