# ICPC 2026 Team Command Center

This repository is the command center and weapon library for our ICPC team.

## Team Goals

- Improve problem-solving speed
- Build a reliable algorithm library
- Practice contest strategy
- Reduce bugs and wrong submissions
- Prepare for ICPC-style contests

## Repository Structure

- `algorithms/` - reusable algorithm implementations
- `templates/` - default C++ templates
- `contests/` - practice contest submissions
- `problems/` - solved, unsolved, and review problems
- `notebook/` - printable team notebook
- `scripts/` - helper scripts for running and testing code
- `docs/` - team rules, strategy, and review notes

## Team Rules

1. Every algorithm file must include:
   - Purpose
   - Time complexity
   - Space complexity
   - Example usage

2. Every contest practice must include:
   - Final accepted code
   - Mistakes made
   - Lessons learned

3. Code should be short, readable, and contest-ready.

## Main Language

C++17
