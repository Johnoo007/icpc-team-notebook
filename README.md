# 🚀 ICPC 2026 Team Command Center

## 🎯 Purpose
This repository serves as the central hub for our ICPC journey. It is a "Living Textbook" designed for algorithm storage, competitive practice, and team strategic knowledge.

## 📂 Main Folders

- **`algorithms/`** - Reusable algorithm code (The "Holy Bible" for our team)
  - *Data Structures, Graph, DP, Math, Geometry, String*
- **`templates/`** - Starting code templates (optimized for speed and debugging)
- **`contests/`** - Mock contests and real contest practice (Solution archives)
- **`practice/`** - Topic-based problem solving (Categorized by difficulty or tags)
- **`docs/`** - Team knowledge, common mistakes, and contest strategies
- **`scripts/`** - Automation tools for compiling, running, and stress testing

## 💻 Main Language
- **C++17** (Standard optimized for competitive programming)

---

## 🛠 Setup & Development
### Local Environment
- **Compiler:** Clang++ (macOS) / G++ (Windows)
- **Build System:** Custom VS Code Tasks (see `.vscode/`)
- **Headers:** Custom `<bits/stdc++.h>` implementation for local IntelliSense.

### Git Workflow
- All binaries (executables without extensions) are automatically ignored via `.gitignore`.
- Please run `git rm --cached <file>` if any compiled files accidentally slip into the repository.

## 🤝 Team Guidelines
1. **Readable Code:** Even in a contest, aim for clean logic in the `algorithms/` folder.
2. **Post-Mortem:** After every contest, update `docs/` with at least one "Lesson Learned."
3. **Template First:** Always start from `templates/template.cpp` to ensure consistent setup.
